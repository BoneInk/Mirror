# Mirror v1.3.4 · macOS (build 16)

修复 v1.3.3 安装包中源码编辑区空白的问题，保留 PDF 章节目录修复。已安装 v1.3.3 的用户请升级到本版本。

- 编辑器显式跟随滚动视图宽度，防止文本视图宽度为零导致正文不可见。
- 通用应用通过原生 SwiftPM 后端分别构建两种架构，最低系统版本继续由 Package.swift 指定为 macOS 14，避免新版构建引擎将 SDK 版本误标记为 14.0。
- 原生显示回归增加编辑器宽度、文本容器及正文布局检查，覆盖编辑、分栏、长文滚动和紧凑深色模式；模拟旧 SDK 标记的回归也通过。

## 下载与安装

- `Mirror-1.3.4.dmg`：macOS 14+，同时包含 Intel 与 Apple Silicon 架构。
- `SHA256SUMS.txt`：SHA-256 校验文件。

打开 DMG，将 Mirror 拖入 Applications，重新启动 Mirror。安装包使用 ad-hoc 签名，尚未完成 Apple 公证；首次打开说明见安装包内文档。Windows 继续使用 [v1.3.2](https://github.com/BoneInk/Mirror/releases/tag/v1.3.2)。

## 验证

原生编辑器显示、长文档滚动与 PDF 目录回归通过。通用应用的最低系统版本、SDK 标记、签名与 DMG 校验通过，并核对实际安装版的正文显示。
