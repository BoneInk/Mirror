# Mirror v1.3.5 · macOS (build 17) / Windows

两端加入 GitHub Releases 自动更新：后台检查、下载和校验，在正常退出后安装，下次启动即为新版。保留 PDF 章节目录与源码编辑区显示修复。

- 默认每天自动检查一次，同时支持手动检查和关闭自动更新。
- 校验安装包 SHA-256，跳过草稿、预发布及不匹配当前平台的安装包；版本按数值比较。
- macOS 校验应用标识、版本、架构和签名，退出后替换应用；失败时回退。
- Windows 安装版通过 NSIS 静默更新，便携版自动替换原 EXE；安装前备份，验证失败时回退安装文件。
- “立即重启更新”先保留草稿和会话。无安装目录写入权限时可打开已下载的安装包手动更新。

## 下载与安装

- `Mirror-1.3.5.dmg`：macOS 14+，Intel / Apple Silicon 通用应用。
- `Mirror-1.3.5-windows-x64-setup.exe`：Windows 10 / 11 x64 安装版。
- `Mirror-1.3.5-windows-x64-portable.exe`：Windows 10 / 11 x64 便携版。
- `SHA256SUMS.txt`：上述安装包的 SHA-256 校验文件。

首次升级到 v1.3.5 请手动安装，此后的更新可自动安装。macOS 使用 ad-hoc 签名，尚未完成 Apple 公证；首次打开方式见 DMG 内说明。

更新设置：macOS「设置 → 软件更新」或 Mirror 菜单「检查更新」；Windows「设置 → 关于 Mirror」。

## 验证

更新检查测试覆盖版本排序、平台筛选、每日限流、手动重试、关闭自动更新、下载大小与校验和失败。macOS 安装测试覆盖等待退出、成功替换、取消自动安装、签名失败、替换失败回退和保留已手动安装的新版本。Windows CI 验证实际 NSIS 与便携版的退出后更新和失败回退。两端界面、文档显示与 PDF 目录回归通过。
