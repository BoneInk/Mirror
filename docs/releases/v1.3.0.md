# Mirror v1.3.0

- 支持在 Mirror 中继续已有 Codex 会话：查看历史、引用文档、多轮对话、流式回复和停止生成，消息保存在原会话中。发送前需退出 Codex 桌面；桌面专属工具与交互批准暂不支持。
- Markdown 文件筛选图标移到搜索框内，悬停显示中文提示，开启时高亮。
- 补齐工作区与搜索菜单的中文翻译，修复双击后文件名变白的问题。
- 从文档链接打开另一份 Markdown 时回到文档开头。
- 编辑／分栏／阅读模式改为全局偏好，切换文档和重启后保持。
- 调整文件列表选中样式，移除系统蓝色选中条与白色卡片叠加，统一为主题色圆角背景。

## 安装

下载 Mirror-1.3.0.dmg，将 Mirror 拖入 Applications。支持 macOS 14+，安装包同时包含 Intel 与 Apple Silicon 架构。首次打开说明见安装包内文档。

## 验证与边界

已有会话续聊、会话选择、引用和文档状态回归测试通过；构建通用 macOS 应用并校验安装包。真实模型续聊仍需在退出 Codex 后人工验收。续聊使用只读文件沙箱；回到 Codex 执行修改前请检查会话权限设置。连接异常时需刷新历史核对，避免重复发送。
