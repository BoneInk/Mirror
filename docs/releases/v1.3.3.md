# Mirror v1.3.3 · macOS (build 15)

修复 macOS 导出 PDF 后，阅读器左侧章节目录丢失的问题。导出的 PDF 保存并重新打开后，仍保留标题层级和章节跳转。

- 修复 PDFKit 保存 WebKit 生成的 PDF 时，未将新增章节书签写入文件的问题。
- 导出时将页面复制到新 PDF 文档，再写入章节书签，保留正文和链接。
- 回归验证覆盖中文标题、重复标题、跳级标题、跨页跳转、无标题文档及正文与链接保留。
- 构建脚本通过 Swift 查询实际产物目录，兼容新版 Swift 构建引擎的输出路径。

## 下载与安装

- `Mirror-1.3.3.dmg`：macOS 14+，同时包含 Intel 与 Apple Silicon 架构。
- `SHA256SUMS.txt`：SHA-256 校验文件。

打开 DMG，将 Mirror 拖入 Applications。安装包使用 ad-hoc 签名，尚未完成 Apple 公证；首次打开说明见安装包内文档。

本次更新 macOS；Windows 继续使用 [v1.3.2](https://github.com/BoneInk/Mirror/releases/tag/v1.3.2)。章节书签修复适用于 Mirror 的“导出 PDF”，系统打印对话框的“存储为 PDF”沿用打印流程。

## 验证

PDF 导出及 Markdown 渲染回归测试通过。通用应用构建、签名与 DMG 校验通过。
