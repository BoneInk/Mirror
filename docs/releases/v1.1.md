Mirror v1.1 改进了引用提问、智能体配置和对话记录管理。

- 划词提问入口跟随选区结束端，支持跨行、反向选择和窗口边缘避让。
- 输入框默认 Return 发送，⌘ Return 换行；中文输入法选词时不误发送。
- 原生对话气泡提供显示动画、自动聚焦、原文定位、流式回答和连续追问；全局保持一个气泡，支持 Esc 和点击外部关闭。
- 引用位置可保留对话标记。气泡菜单支持删除单条本机记录，设置支持搜索、批量选择和批量删除；删除后的后台回调不会恢复记录。
- 支持 Codex、Claude Code、CodeBuddy、Cursor、Kimi、Qoder、OpenCode、Pi Agent 的命令行接入，Hermes / OpenClaw 的 Agent HTTP 服务，D-Chat Smartwork 原生本地服务和 WorkBuddy 本地助理 Open API。
- 提供 DeepSeek Harness、千问办公及其他服务的可配置桥接。千问办公尚未确认公开问答协议，需自行配置办公 Agent 包装命令或兼容服务。
- 本地命令及监听端口检测、Smartwork 协议健康检查；认证信息保存在 macOS 钥匙串。
- 系统目录授权提示和文件选择面板不会关闭气泡或丢失输入；Esc 和主动点击气泡外仍可关闭。
- 历史对话保留智能体配置归属，切换智能体可另起对话；旧 Codex 记录兼容保留。
- 更新原生界面样式和应用图标。

安装：下载 Mirror-1.1.dmg，将 Mirror.app 拖入 Applications。支持 macOS 14 及以上，安装包同时包含 Intel（x86_64）和 Apple Silicon（arm64）。

验证覆盖模拟智能体调用、双向选区定位、输入法与快捷键、单条/批量删除、后台取消、标记刷新及历史兼容。Smartwork 已完成本机健康检查；新接入的问答协议通过模拟服务验证，未发送真实推理请求。WorkBuddy 需配置开放平台 Access Token，使用共享本地助理通道；停止等待不终止客户端任务。删除仅影响 Mirror 本机记录，不删除智能体服务端会话。

完整接入方式与限制见 [使用说明](https://github.com/BoneInk/Mirror/blob/v1.1/README.md#多智能体引用提问)。安装包采用 ad-hoc 签名，未做 Apple Developer ID 公证。
