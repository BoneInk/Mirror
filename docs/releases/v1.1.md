Mirror v1.1 在 v1.0 的 Markdown 写作与阅读体验上，新增围绕原文的 AI 对话。

## 相比 v1.0 的主要变化

- **划词即问。** 在原文旁打开对话气泡，支持流式回答、连续追问和返回引用位置。Return 发送、⌘ Return 换行，Esc 或点击外部关闭；系统文件授权弹窗不会打断输入。
- **连接自己的智能体。** 支持 Codex、Claude Code、Smartwork 等多种本机运行时和服务，也可配置自定义桥接。气泡内可切换智能体、模型及支持的思考深度，并记住选择；Codex、Smartwork 和兼容 HTTP 服务支持自动读取可用模型。
- **讨论可以回顾。** 引用位置保留对话标记，点击即可继续讨论；支持单条删除、批量管理，也可关闭记忆功能。
- **更统一的原生界面。** 调整导航、对话气泡和应用图标，浅色主题采用白色与中性浅灰，搭配陶橙色强调重点，减少大块底色对阅读的干扰。

## 下载

下载 **Mirror-1.1.dmg**，将 Mirror 拖入 Applications。支持 macOS 14+，同时包含 Intel / Apple Silicon。安装包采用 ad-hoc 签名，尚未完成 Apple 公证。

首次打开若提示“Apple 无法验证 Mirror”，请先点“完成”，再到 **系统设置 → 隐私与安全性 → 仍要打开**，按提示确认。仅在确认安装包来自本项目 Release 且信任来源时操作。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

不同智能体需要各自的安装、登录或服务配置；千问办公等通过自定义桥接接入。详见[智能体接入说明](https://github.com/BoneInk/Mirror/blob/main/docs/agents.md)。

当前安装包为 v1.1（构建号 6），代码对应 [5e746aa](https://github.com/BoneInk/Mirror/commit/5e746aa)。保留首次发布的 v1.1 标签，文件校验值见 SHA256SUMS.txt。
