Mirror v1.1：在原文旁提问、回顾讨论，并连接你自己的智能体。

本次安装包更新包含：

- 默认主题改为白色内容区与米灰工作区配色，同步更新界面截图。
- 气泡内可配置模型与支持的思考深度，并记住配置。
- 气泡详情和原文标记支持直接删除，设置支持批量管理。
- 手动切换智能体后，同步记住设置中的默认值。
- 修复引用高亮残留和整段列表误高亮；兼容系统文件授权弹窗。
- 保留选区末端定位、Return 发送、⌘ Return 换行与多智能体接入。

下载 **Mirror-1.1.dmg**，拖入 Applications。支持 macOS 14+，包含 Intel / Apple Silicon。安装包为 ad-hoc 签名，尚未 Apple 公证。

本次更新保留 v1.1 标签；安装包的代码对应 [ad7d992](https://github.com/BoneInk/Mirror/commit/ad7d992)，包含首次发布后的修复。校验值见 SHA256SUMS.txt。
