Mirror v1.2.0 增加已有 Codex 会话引用和文档管理快捷操作。

## 新功能

- 选中文字后，可从编辑器或预览的右键菜单选择「引用到 Codex 会话…」。在 Mirror 内预览本机未归档会话，搜索、分页并选择目标，将原文、文件路径与位置填入 Codex 草稿。
- 文档标签右键菜单增加「关闭其他所有文档」，保留点击的文档；取消关闭或切换受阻时停止批量操作。
- 文件侧栏跟随当前文档：保留包含文档的工作区，否则打开文档所在目录，展开并定位对应文件。
- 文档标签和工作区文件、文件夹右键菜单增加「复制绝对路径」，未保存文档禁用，复制后显示提示。

## Codex 引用说明

引用需要本机 Codex 桌面应用。引用会替换目标会话原有的未发送草稿，请先保存原草稿，再在 Codex 中核对并发送。列表来自本机 app-server；不包含远程主机或云端 ChatGPT 会话。Mirror 显示的成功提示代表系统接受打开请求，不代表消息已发送。

已验证真实会话读取和 Mirror 两个选区入口；Codex 输入框接收受自动化工具限制，仍需人工核对。详见[会话引用说明](https://github.com/BoneInk/Mirror/blob/v1.2.0/docs/codex-thread-reference.md)。

## 下载

下载 **Mirror-1.2.0.dmg**，将 Mirror 拖入 Applications。支持 macOS 14+，包含 Intel / Apple Silicon 通用应用，构建号 9。文件校验值见 SHA256SUMS.txt。

安装包采用 ad-hoc 签名，尚未完成 Apple 公证。首次打开方式见[项目说明](https://github.com/BoneInk/Mirror#开始使用)。
