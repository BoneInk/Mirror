# Mirror v1.3.1 · Windows

Windows 版本同步 macOS 1.3.0 build 13 的主要阅读、编辑与智能体功能，提供 x64 安装版和便携版。本次没有重新打包 macOS；macOS 用户继续使用 v1.3.0。

- UI 同步纸张画布、源码高亮、九套主题、自定义配色、阅读排版、宽度和悬浮工具，保留 Windows 窗口控制。
- 工作区全文搜索、文件变化监听、未保存草稿冲突横幅、相对文档链接、文件拖放与源代码行滚动同步。
- Mermaid 支持缩放、平移、复位与外框宽高调整，交互不改变 Markdown 或导出。
- Codex 原会话列表、历史预览与续聊；支持 Smartwork、WorkBuddy、Claude Code、CodeBuddy、Cursor、Kimi、Qoder、OpenCode、Pi Agent 和兼容服务。
- 智能体检测、模型列表、思考深度与配置复制；会话保留旧配置和历史，凭据由 Windows 加密保存。
- 补齐元数据、提示块、单行脚注和阅读引用标记。
- Electron 更新到 44.5.1，依赖审计为零已知漏洞。

## 下载

- `Mirror-1.3.1-windows-x64-setup.exe`：NSIS 安装版。
- `Mirror-1.3.1-windows-x64-portable.exe`：便携版。
- `SHA256SUMS.txt`：下载文件校验。

支持 Windows 10 / 11，产物未签名。

## 验收与边界

Windows 实机生产构建、14 项单元测试、10 项 Electron 桌面回归通过；验收覆盖保存与外部冲突、快照恢复、HTML/PDF 导出、Mermaid 操作、工作区搜索、主题与排版恢复、原会话选择、协议调用链及凭据加密。本机 Codex CLI 模型列表读取通过，生成测试使用本机 fixture。

Windows 文件预览仍限 Markdown / 纯文本，未包含 macOS Quick Look、源码行号边栏、Markdown 清理助手或完整多行脚注。原 Codex 会话续聊前需退出 Codex 桌面，完成、停止或异常后先刷新历史核对。真实智能体生成、安装/卸载、文件关联和 ARM64 尚需在目标环境单独验收。具体限制与记录见仓库 `Windows/docs/validation.md`。
