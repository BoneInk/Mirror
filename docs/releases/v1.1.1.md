Mirror v1.1.1 修复 Markdown 下划线被误识别为强调标记的问题。

## 修复

- 保留 `foreign_keys`、`retention_anchor`、`copied_at` 等字段名中的下划线，避免跨字段错误配对导致下划线消失、整段文字变成斜体。
- 下划线斜体和粗体增加词边界与空白检查，并补充中文、字段名、转义字符及代码片段的回归用例。

## 下载

下载 **Mirror-1.1.1.dmg**，将 Mirror 拖入 Applications。支持 macOS 14+，包含 Intel / Apple Silicon 通用应用，构建号 8。文件校验值见 SHA256SUMS.txt。

安装包采用 ad-hoc 签名，尚未完成 Apple 公证。首次打开方式见[项目说明](https://github.com/BoneInk/Mirror#开始使用)。

## 验证

- Markdown 渲染回归与 WebKit / PDF 冒烟测试通过。
- Swift 构建通过；发布安装包使用双架构 release 构建。
