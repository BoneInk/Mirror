# Mirror — 镜像折页

The mirrored paper folds form an M, connecting the app name with reading and writing. A warm porcelain tile and terracotta paper retain Mirror's existing palette while giving the Dock and title bar one shared mark.

- Master: `MirrorIcon-master.png`, generated with the built-in image_gen tool.
- Runtime assets: `../AppIcon.png` and `../AppIcon.icns`.
- Rebuild: run `swift scripts/generate-app-icon.swift` from the repository root.
- Packaging keeps the master image's alpha channel and generates the standard 16–1024 px macOS icon family.

## Selected master generation prompt

Use case: logo-brand. Create ONE final production macOS application icon for Mirror, a refined native Markdown writing and reading app. Brand concept: mirrored folded paper, an abstract capital M that also evokes an open book. Square 1024x1024 RGBA PNG, genuinely transparent pixels outside the icon, no checkerboard baked in. Centered macOS rounded superellipse tile occupying approximately 84% of the canvas width and height, consistent transparent margins, restrained soft shadow within margins. Tile material: very pale warm porcelain ivory (#F5F2EC), a fine softly beveled edge and subtle studio lighting from upper left. Center mark: a single highly distinctive broad sculptural M built from two mirrored folded-paper ribbons, with two upright broad outer stems and folded inward diagonals meeting at a low central valley; precise symmetrical geometry, compact silhouette, rounded outer tips, convincingly simple folds, saturated muted terracotta-orange (#C66B45) front planes with darker burnt-sienna fold planes and delicate peach lit edges. The M occupies roughly 58% of the tile width and 54% of its height. This is a premium designer stationery / writing app identity, contemporary and quiet, handsome at 32px, strongly recognizable silhouette, only a few large planes, exceptionally clean craftsmanship. Straight-on orthographic view, no perspective on the outer tile. No text, no wordmark, no Chinese glyph, no pen, no extra symbols, no decorative sparkle, no glass rainbow, no chrome, no tiny lines, no circular border. Output ONLY the single ready-to-use icon, no presentation board, no mockup scene, no variants.
